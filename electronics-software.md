# Domain 2: Electronics and Software

## Research Summary
- India's semiconductor mission (ISM 2.0) budget: ₹1.25L Cr; domestic market expected >$60B by 2026
- India imports ~$35B of semiconductors annually (2026)
- Current focus: mature nodes (28nm+), ATPM facilities; Micron, Tata Electronics, CG Power active
- Global shortage 2021-23 exposed dependency; geopolitical Taiwan-China risk drives localization
- ESP32/Arduino ecosystem has >100 open issues on GitHub re: stability, Zigbee, BLE, UART
- India has 5M+ software engineers but <5% work on hardware-near, low-level, or semiconductor design
- PLI scheme covers 50% capex for fabs, but talent pipeline severely deficient — <5,000 trained semiconductor engineers
- Mechatronics integration (mechanical + electronics + software) is a critical gap — no Indian university offers a dedicated mechatronics engineering degree at scale

## The Axiom List
1. Moore's Law (transistor density doubles ~2 years) is decelerating — Dennard scaling ended ~2006
2. All computation is physical — electrons move through material, generating heat, limited by speed of light
3. Signal integrity degrades with distance, frequency, and noise — Shannon's theorem bounds channel capacity
4. Software abstraction layers trade performance for developer productivity — every layer adds overhead
5. Security is a function of system complexity — more code = more vulnerabilities
6. The cost of a chip design (mask set) is ~$5M at 28nm, >$50M at 5nm — amortization requires volume
7. Real-time systems require deterministic latency — garbage-collected languages (Java, Python) are unsuitable
8. Embedded systems are constrained by energy (battery), memory (flash/RAM), and compute (clock speed)

## The Derivation (First-Principles)

### Axiom 2 + 4 → The software stack (OS + drivers + framework + app) wastes 50-90% of hardware capability
### Axiom 6 → India cannot compete at leading edge; must target mature nodes + specific verticals
### Axiom 3 + 7 → Edge/IoT devices need deterministic, low-latency firmware — not Python/JS
### Axiom 5 → IoT botnets (Mirai) prove that connected devices are the weakest security link
### Axiom 8 → Every embedded system is a compromise between power, performance, and cost

**Logic Chain:**
- A4: Python → C → Assembly → Silicon — each layer abstracts hardware but adds latency and energy
- A6: For India, 28nm+ nodes for automotive, industrial, consumer are the addressable market
- A3 + A7: Industrial IoT needs deterministic sub-ms response — Linux RT is heavy, bare-metal is hard
- A5: ESP32 has 512KB SRAM — cannot run full TLS/HTTPS stack → security is an unsolved embedded problem
